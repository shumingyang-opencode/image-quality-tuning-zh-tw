13.1 為什麼要一致性

量產時每台相機畫質要一致——「這台偏紅、那台偏綠」是品質災難。

13.2 統計方法

單位間差異
均值 μ、標準差 σ（樣本 N 台）
Δparam = (X − μ) / μ
規格：多數參數 μ ± 3σ 在 ±5–10% 內

13.3 關鍵一致性指標

  • AWB gains 漂移。
  • 曝光/增益差異。
  • 色彩（ΔE 分布）。
  • 雜訊、暗角比。

13.4 校正與把關

  • 每台出廠校準（黑位、LSC、AWB）。
  • 抽樣量測 + SPC。

13.5 練習

  1. 樣本 3–5 台，量測 AWB gains 分布。
  2. 判斷是否在規格內。

13.6 深入：SPC 的基本運用

SPC 概念
樣本 N 台 → 每台量 AWB gains/SNR/DR
算 μ、σ → 畫控制圖（μ±3σ）
超出 → 判定異常 → 追根因

13.7 深入：一致性的根因

  • 感測器批次漂移 → 逐顆校準。
  • 鏡頭批次差異 → LSC/MTF 抽查。
  • 組裝/模組差異 → 出廠 AWB/LSC 校正。

13.8 Worked Example：unit-to-unit 統計

範例
5 台 BlueGain: 1.20,1.18,1.21,1.19,1.22
μ=1.20, σ=0.016
±3σ = ±4.8%（<10% ✓）
台差 = (1.22−1.18)/1.20 ≈ 3.3%

動手：量 3–5 台，算 AWB gains 分布。

EMVA 1288 對應：可再現性（Repeatability）

EMVA 1288 是感測器層的標準量測（QE、飽和、雜訊、動態範圍）。它定義了「感測器送出 RAW 的品質天花板」——以下與本單元對應的規範、公式與調校方向。

EMVA 1288 參數公式/定義本單元驗證
重複性同條件多次量測的 σ（EMVA 要求）unit-to-unit 前提
數值很差時怎麼調（unit-to-unit 漂移）：
  • 現象：同一批樣本的 EMVA 參數離散大。
  • 調校方向：先確認「量測本身可再現」；若感測器批次漂移 → 出廠校正（黑位/LSC/AWB）需逐顆，tuning 需留裕度。

本單元 EMVA 門檻與數值差調校

量測門檻差時調校
Repeatability同條件多次量測漂移 < 5%高 → 量測條件/樣本
unit-to-unitμ ± 3σ 在 ±5–10%超 → 出廠校正/批次管控

13.9 補強：一致性不是只看平均值

平均值合格但尾端離群仍可能造成客訴。除了 μ、σ 與 ±3σ，應查看 min/max、箱型分布、批次與時間順序；先用重複量測估計量測噪聲，再把真正的 unit-to-unit 變異分開。AWB、LSC、SNR、MTF50、ΔE 應各自設門檻，不宜用單一總分掩蓋風險。

SPC 判讀
同一台重複 3 次 → 量測 σ_repeat

13.10 補強練習：找離群與根因


  1. 用至少 10 台計算 AWB gains、SNR、MTF50、ΔE 的 μ/σ。
  2. 畫出批次或序號控制圖，標記超過 ±3σ 的樣本。
  3. 回查該台的 EMVA、LSC、溫度與校正版本，寫出可驗證的根因假設。

進階真實情境 Worked Example：SPC 控制圖 + 異常根因追溯


進階範例：量產 SPC 控制圖應用
場景：量產 100 台，AWB BlueGain 控制圖出現異常。

追溯流程：
1. 控制圖：BlueGain μ=1.20, σ=0.02
   第 87 台 = 1.28（超出 +3σ）
2. 追溯該台：感測器批次 B12、組裝日期 3/15
3. 同批次另 2 台也偏高 → 感測器批次問題
4. EMVA 檢查：該批次 η 偏低 5%（光譜響應偏移）
5. 對策：AWB 校正參數加溫度/批次補償

為什麼這條路徑：
SPC 發現異常 → 批次追溯 → 感測器層確認 →
才能精準修正而非「每台都重調」。


動手：用 SPC 控制圖追蹤一批量產數據的異常。


為什麼選這條調校路徑：SPC 控制圖能發現離群樣本，但真正的價值在於追溯根因——從異常數字追溯到感測器批次、組裝條件，才能精準修正。



進階原理：CUSUM 控制圖的敏感度


傳統 Shewhart 控制圖（μ±3σ）只能偵測大幅偏離；CUSUM（累積和）控制圖對「小幅度但持續的漂移」更敏感。量產 IQ 監控建議兩者並用。


陷阱案例：「用 Shewhart 圖看都 OK → 但 CUSUM 圖顯示第 50 台後有持續上升趨勢」——感測器批次逐漸漂移，Shewhart 漏看但 CUSUM 捕捉。



診斷式疑難排解





症狀可能原因解決方案


平均值 OK 但有離群樣本感測器批次差異或組裝問題追溯離群樣本的批次/序號 → 根因


AWB gains 一致性差感測器光譜響應批次漂移逐顆出廠 AWB 校正


量測重複性差（同一台每次不同）量測條件不穩定固定光源/曝光/溫度 + 多次平均


SPC 圖顯示趨勢但未超限小幅度持續漂移改用 CUSUM 控制圖偵測趨勢


不同批次間 SNR 差異大感測器製程批次差異建立批次 SNR 基線 + 差異補償
