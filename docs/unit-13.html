單元 13 · 一致性驗證（unit-to-unit）

多台一致性、統計、規格門檻

13.1 為什麼要一致性

量產時每台相機畫質要一致——「這台偏紅、那台偏綠」是品質災難。

13.2 統計方法

單位間差異
均值 μ、標準差 σ（樣本 N 台）
Δparam = (X − μ) / μ
規格：多數參數 μ ± 3σ 在 ±5–10% 內

13.3 關鍵一致性指標

  • AWB gains 漂移。
  • 曝光/增益差異。
  • 色彩（ΔE 分布）。
  • 雜訊、暗角比。

13.4 校正與把關

  • 每台出廠校準（黑位、LSC、AWB）。
  • 抽樣量測 + SPC。

13.5 練習

  1. 樣本 3–5 台，量測 AWB gains 分布。
  2. 判斷是否在規格內。

13.6 深入：SPC 的基本運用

SPC 概念
樣本 N 台 → 每台量 AWB gains/SNR/DR
算 μ、σ → 畫控制圖（μ±3σ）
超出 → 判定異常 → 追根因

13.7 深入：一致性的根因

  • 感測器批次漂移 → 逐顆校準。
  • 鏡頭批次差異 → LSC/MTF 抽查。
  • 組裝/模組差異 → 出廠 AWB/LSC 校正。

13.8 Worked Example：unit-to-unit 統計

範例
5 台 BlueGain: 1.20,1.18,1.21,1.19,1.22
μ=1.20, σ=0.016
±3σ = ±4.8%（<10% ✓）
台差 = (1.22−1.18)/1.20 ≈ 3.3%

動手：量 3–5 台，算 AWB gains 分布。

EMVA 1288 對應：可再現性（Repeatability）

EMVA 1288 是感測器層的標準量測（QE、飽和、雜訊、動態範圍）。它定義了「感測器送出 RAW 的品質天花板」——以下與本單元對應的規範、公式與調校方向。

EMVA 1288 參數公式/定義本單元驗證
重複性同條件多次量測的 σ（EMVA 要求）unit-to-unit 前提
數值很差時怎麼調（unit-to-unit 漂移）：
  • 現象：同一批樣本的 EMVA 參數離散大。
  • 調校方向：先確認「量測本身可再現」；若感測器批次漂移 → 出廠校正（黑位/LSC/AWB）需逐顆，tuning 需留裕度。

本單元 EMVA 門檻與數值差調校

量測門檻差時調校
Repeatability同條件多次量測漂移 < 5%高 → 量測條件/樣本
unit-to-unitμ ± 3σ 在 ±5–10%超 → 出廠校正/批次管控

13.9 補強：一致性不是只看平均值

平均值合格但尾端離群仍可能造成客訴。除了 μ、σ 與 ±3σ，應查看 min/max、箱型分布、批次與時間順序；先用重複量測估計量測噪聲，再把真正的 unit-to-unit 變異分開。AWB、LSC、SNR、MTF50、ΔE 應各自設門檻，不宜用單一總分掩蓋風險。

SPC 判讀
同一台重複 3 次 → 量測 σ_repeat

13.10 補強練習：找離群與根因


  1. 用至少 10 台計算 AWB gains、SNR、MTF50、ΔE 的 μ/σ。
  2. 畫出批次或序號控制圖，標記超過 ±3σ 的樣本。
  3. 回查該台的 EMVA、LSC、溫度與校正版本，寫出可驗證的根因假設。
