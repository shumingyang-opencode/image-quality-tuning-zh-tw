15.1 報告的用途

  • 向客戶證明「達標」。
  • 向自己「可再現、可追蹤」。
  • 向量產「可驗收」。

15.2 報告結構

IQ 驗證報告範本
1. 測試條件（光源/圖卡/設備）
2. 樣本資訊（感測器/鏡頭/ISP/版本）
3. 各維度結果（曝光/色彩/雜訊/解析度/均勻度/DR）
4. 一致性（unit-to-unit）
5. 標準對照（ISO/EMVA）
6. 結論與簽核

15.3 規格書（SPEC）

  • 明列「參數 → 量測方法 → 目標值 → 門檻」。
  • 例：ΔE avg<3、MTF50 ≥0.5、暗角比 ≥0.9。

15.4 驗收流程

  1. 自測（自家報告）。
  2. 客戶測（依相同 SPEC）。
  3. 差異協調（量測條件須一致）。

15.5 練習

  1. 用範本寫一份驗證報告。
  2. 定義一份簡單規格書。

15.6 深入：報告的「可重現性」承諾

一份合格的 IQ 報告，別人照條件重測應得相近數字。因此：量測條件、工具版本、EMVA 版本、樣本 ID 都要寫清。

15.7 深入：規格書的「可驗收」寫法

SPEC 範例條目
項目: 色彩保真度
量測: 24 色卡, D65, 固定曝光
目標: ΔE00 avg < 3, max < 6
方法: CIE DE2000（標明版本）
判定: 全色塊合格

15.8 Worked Example：SPEC 條目撰寫

範例
項目: 低光雜訊
量測: 5 lux, 灰卡, 固定曝光
指標: SNR（EMVA 定義）
目標: ≥ 20 dB
方法: 灰框 σ + 均值
判定: 全測點合格

動手：為你系統寫 3 條 SPEC。

EMVA 1288 對應：報告中的 EMVA 章節

EMVA 1288 是感測器層的標準量測（QE、飽和、雜訊、動態範圍）。它定義了「感測器送出 RAW 的品質天花板」——以下與本單元對應的規範、公式與調校方向。

EMVA 1288 參數公式/定義本單元驗證
報告格式EMVA 1288 報告範本（參數表+曲線）一致性報告
數值很差時怎麼調（客戶質疑感測器規格）：
  • 現象：客戶要 EMVA 原始量測而非廠商 datasheet。
  • 調校方向：依 EMVA 1288 標準流程自測並附量測條件——報告要能重現。

項目規範

參數表η/飽和/σ_d/PRNU/DSNU/SNR/DR 全列
