10.1 缺陷像素（DPC）

  • Dead pixel：固定黑；Hot pixel：固定亮。
  • 感測器端 DPC 先修，ISP 端再補。
  • 驗證：黑框 RAW 的 max 應被壓制。

10.2 眩光（Flare/Ghost）

  • 雜散光造成的霧化或鬼影。
  • ISO 18844 量測。
  • 鏡頭鍍膜/遮光為主，ISP 端能補有限。

10.3 Moiré

  • 細紋理的彩色假影。
  • 假色抑制（低通）降低但傷 MTF。
  • 用細網格圖卡判定。

10.4 幾何畸變與色差

  • 畸變：直線變彎 → 鏡頭/校正表。
  • 色差：邊緣彩邊 → 鏡頭/ISP 校正。
  • 驗證：格線圖卡量畸變率。

10.5 練習

  1. 黑框檢查缺陷像素。
  2. 格線圖卡量畸變。

10.6 深入：缺陷像素的量測與規格

量測壞點
暗框 RAW：與鄰域差異 > 門檻 → hot pixel
亮框：與鄰域差異 > 門檻 → dead pixel
統計比例 → 對照 EMVA/規格（< 0.01–0.1%）

10.7 深入：Moiré 的根源

Moiré 源自「感測器取樣頻率 vs 場景頻率」的混疊——不是單一模組可完全解決。光學低通濾波、demosaic 假色抑制、解析度取捨三者要一起看。

10.8 Worked Example：壞點判定

範例
暗框 RAW：
像素 P = 800（鄰域 ~100）
差值 700 > 門檻（如 5×σ）→ hot pixel
全圖統計：18 顆 / 5MP ≈ 0.00036%（<0.01% ✓）
DPC 啟用後重測 → 壓制 ✓

動手：統計你的壞點率並確認 DPC 生效。

EMVA 1288 對應：缺陷像素與壞點

EMVA 1288 是感測器層的標準量測（QE、飽和、雜訊、動態範圍）。它定義了「感測器送出 RAW 的品質天花板」——以下與本單元對應的規範、公式與調校方向。

EMVA 1288 參數公式/定義本單元驗證
熱像素EMVA 量測暗框離群點DPC 需求
數值很差時怎麼調（熱像素多）：
  • 現象：EMVA 暗框顯示熱像素比例超標。
  • 調校方向：感測器端 DPC 先修；若仍多 → 檢討散熱/曝光時間（暗電流隨溫升）。

本單元 EMVA 門檻與數值差調校

量測門檻差時調校
壞點率< 0.01%（佳）高 → DPC + 散熱/曝光
暗電流< 50 e⁻/s（一般）高 → 降溫/縮曝光

10.9 補強：用標準化測試拆分根因

ISO 18844 的 flare、ISO 12233 的 SFR/Moiré 與格線畸變測試不能混成一張「清晰度」分數。先以 RAW 或關閉相關 ISP 的結果定位光學問題，再開啟 DPC、demosaic、畸變校正逐層確認改善是否引入 halo、細節損失或邊緣裁切。

現象隔離方法可接受證據
flare 霧化固定光源角度、遮光件與曝光黑位/對比相對差異
Moiré細網格改變角度與頻率假色區域與 MTF 損失
畸變/色差格線圖、中心到邊緣 ROI幾何百分比與彩邊像素

10.10 補強練習：建立問題樹

  1. 各拍一張黑框、細網格、格線與逆光圖，保存原始影像。
  2. 對每個異常標記是光學、感測器、demosaic、DPC 或校正表問題。
  3. 只改一個模組，回報改善指標與副作用。
看完這單元你應該能說出：
  • 缺陷像素與 DPC。
  • 眩光與 ISO 18844。
  • Moiré、畸變、色差的判定。

進階真實情境 Worked Example：DPC + Flare + Moiré 綜合診斷

進階範例：工業視覺系統綜合 IQ 診斷
場景：工廠生產線，影像出現「邊緣彩邊 + 紋理假影 + 亮點」。

診斷流程：
1. 黑框 → hot pixel 22 顆（DPC 需開啟）
2. 逆光 → 邊緣霧化（Flare，ISO 18844 量測）
3. 細網格 → 彩色 Moiré（假色抑制不足）
4. 逐項處理：
   - DPC 開啟 → 亮點消失
   - 加遮光罩 → Flare 降低 40%
   - 調 demosaic 假色抑制 → Moiré 消失
5. 最終驗證：三項異常全消除

為什麼這條路徑：
多個 IQ 問題同時出現 → 必須隔離測試 →
逐項確認根因，避免「改一個壞另一個」。

動手：在你的系統做一次多模組綜合診斷。

為什麼選這條調校路徑：多個 IQ 問題同時出現時，必須用隔離測試逐項確認根因——黑框查 DPC、逆光查 Flare、細網格查 Moiré，避免改一個壞另一個。

進階原理：Flare 的光學建模

Flare（眩光）分為 veiling glare（均勻霧化）和 ghost（鬼影）。Veiling glare 可用 PSF（點擴散函數）建模，ghost 可用鏡片表面反射幾何追蹤。Flare 的嚴重程度與鏡頭鍍膜品質、遮光設計、光源入射角度直接相關。

陷阱案例：「ISP 端加 dehaze 演算法 → Flare 消失」——但 dehaze 只處理 veiling glare，不處理 ghost。真正的解決方案是鏡頭端的遮光與鍍膜。

診斷式疑難排解

症狀可能原因解決方案
黑框有亮點Hot pixel（熱像素）開啟 DPC + 降低暗電流（降溫/縮曝光）
逆光場景邊緣霧化Flare（眩光）加遮光罩 + 檢查鏡頭鍍膜
細紋理出現彩色假影Moiré（混疊）開啟假色抑制 + 接受 MTF 略降
直線變彎幾何畸變（鏡頭）套用畸變校正表或換鏡頭
邊緣彩邊色差（鏡頭軸向/横向）鏡頭端校正 + ISP 色差補償

進階挑戰題

  1. 建立一個「IQ 問題診斷決策樹」：從「影像異常」出發，逐步隔離是 DPC/Flare/Moiré/畸變/色差中的哪一個，並標出每個分支的量測方法。
  2. 在同一鏡頭上，分别量測 DPC 開/關、假色抑制開/關、畸變校正開/關的 MTF 變化，說明每個模組對解析度的影響。
  3. 設計一個「多模組副作用檢查」流程：每開啟一個 ISP 模組後，除了檢查它改善的指標外，還需檢查哪些可能的副作用？
