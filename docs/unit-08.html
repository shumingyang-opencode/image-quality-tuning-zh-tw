8.1 MTF 原理

MTF（調制轉換函數）描述對比隨空間頻率衰減。

MTF 定義
MTF(f) = (C_max − C_min) / (C_max + C_min) @ 頻率 f

8.2 SFR 量測（ISO 12233）

  • 拍斜邊（slanted edge）圖卡。
  • 沿垂直方向取邊緣響應 → 傅立葉轉換 → SFR(f)。
  • 關鍵值：MTF50（對比降 50% 的頻率）。
門檻（依應用）
MTF50（中心）≥ 0.4–0.6 cycles/pixel
角落 MTF ≥ 0.5 × 中心（均勻度）

8.3 Demosaic 與 MTF

  • demosaic 影響解析度與 Moiré 的平衡。
  • 假色抑制（anti-aliasing）降低 MTF 但去 Moiré。

8.4 Sharpen 調校

  • Sharpen 拉回邊緣對比，但放大雜訊。
  • 與 NR 成對調校。
  • 過度 → 光暈（halo）+ 過銳。

8.5 練習

  1. 拍 SFR chart，量測 MTF50。
  2. 調 Sharpen，觀察 MTF 與雜訊變化。

8.6 深入：MTF 量測的常見誤區

  • 斜邊角度過大/過小 → MTF 偏差。
  • 過曝邊緣 → 飽和 → MTF 高估。
  • 雜訊 → MTF 低估。
量測紀律：固定曝光（不飽和）、固定斜邊、確認 SNR——否則 MTF 數字不可信。

8.7 深入：Sharpen 對 MTF 的「假提升」

Sharpen 會讓 SFR 在特定頻段「拱起」→ MTF50 上升，但這是邊緣增強，不是真實解析度。驗收要區分「真實 MTF」與「銳化後 MTF」。

8.8 Worked Example：MTF50 判定

範例
SFR chart 量測：
中心 MTF50 = 0.52 cycles/pixel ✓（≥0.4）
角落 MTF50 = 0.18
均勻度 = 0.18/0.52 ≈ 0.35（角落差）

調校：先查角落 SNR（雜訊？）→ 再查鏡頭
Sharpening 只救邊緣，不救「真實解析度不足」

動手：量測中心/角落 MTF50，評估均勻度。

EMVA 1288 對應：SNR 對 MTF 的可信度

EMVA 1288 是感測器層的標準量測（QE、飽和、雜訊、動態範圍）。它定義了「感測器送出 RAW 的品質天花板」——以下與本單元對應的規範、公式與調校方向。

EMVA 1288 參數公式/定義本單元驗證
SNR 門檻MTF 量測需 SNR 足夠（依 EMVA SNR）SFR 結果可靠度
數值很差時怎麼調（MTF 低）：
  • 現象：MTF 低可能是真解析度差，也可能是雜訊污染邊緣響應。
  • 調校方向：先確認 EMVA SNR 達量測門檻；雜訊高時 SFR 會低估 → 先降噪再量 MTF，否則誤判鏡頭/感測器問題。

本單元 EMVA 門檻與數值差調校

量測門檻差時調校
SNR（量測門檻）SFR 量測前 SNR ≥ 30 dB雜訊高先降噪再量 MTF
MTF50依應用；中心 ≥ 0.4–0.6 c/p低 → 確認非雜訊假象

8.9 補強：SFR 結果的可比性

MTF50 是頻率指標，不等於「肉眼清晰度」。報告需同時保存 slanted-edge ROI、邊緣角度、曝光、SNR、overshoot/undershoot 與單位。ISO 12233 的 SFR 流程可比較解析度，但 Sharpen 造成的高頻拱起要與 RAW/未銳化結果分開呈現。

結果可能根因下一個驗證
中心與角落都低對焦、鏡頭、demosaicRAW 與不同焦點的 SFR
只有角落低場曲、裝配傾斜、角落 SNR四角重複量測與對焦檢查
MTF 高但 halo 明顯Sharpen 過強看 overshoot 與未銳化 MTF

8.10 補強練習：從 chart 到報告

  1. 固定 ISO 12233 圖卡距離與曝光，量中心及四角 MTF50。
  2. 同一影像以 NR/Sharpen 兩組參數重跑，列出 SNR、MTF50 與 halo。
  3. 以「真實解析度、輸出銳利度、量測可信度」三項寫結論。
看完這單元你應該能說出：
  • MTF 原理與定義。
  • SFR 量測與 MTF50 門檻。
  • demosaic/Sharpen 與解析度關係。

進階真實情境 Worked Example：SFR + Demosaic + Sharpen 交叉驗證

進階範例：Moiré vs MTF 的取捨
場景：布料檢測，需要高解析度但 Moiré 嚴重。

交叉驗證流程：
1. Demosaic 關閉假色抑制 → MTF50=0.55, Moiré 嚴重
2. 開啟假色抑制 → MTF50=0.42, Moiré 消失
3. 再加 Sharpen → MTF50=0.48, 輕微 halo
4. 最終：假色抑制 + 中等 Sharpen
5. 驗證：MTF50 ≥ 0.4 且 Moiré 可接受

為什麼這條路徑：
不能只看 MTF50 數字 → 必須同時看
Moiré、halo、紋理保留的主觀評估。

動手：在有 Moiré 風險的場景做 demosaic + sharpen 交叉驗證。

為什麼選這條調校路徑：不能只看 MTF50 數字就判定解析度好壞——必須同時評估 Moiré、halo、紋理保留的主觀感受，才能做出正確的 demosaic 與 sharpen 取捨。

進階原理：Nyquist 頻率與 demosaic 的混疊

Bayer 感測器的 Nyquist 頻率是 pixel pitch 的倒數。超過此頻率的場景細節會產生混疊（aliasing）——Demosaic 演算法試圖重建這些細節，但若混疊已發生，重建結果可能包含假色。

陷阱案例：「把 demosaic 假色抑制完全關掉 → MTF50 看起來最高」——但 Moiré 假影會在實際場景中大量出現。正確做法：保留適度假色抑制，接受 MTF50 略降。

診斷式疑難排解

症狀可能原因解決方案
MTF50 數字高但肉眼看不清Sharpen 過強造成 halo降低 Sharpen + 檢查 overshoot
角落 MTF50 遠低於中心場曲、鏡頭裝配傾斜、角落 SNR檢查焦平面 + 四角重複量測
SFR 量測結果每次不同斜邊角度不固定或曝光不穩固定斜邊角度 + 確認曝光穩定
Moiré 在特定紋理出現感測器 Nyquist 與場景頻率混疊開啟假色抑制（接受 MTF50 略降）
Demosaic 後出現假色假色抑制不足或 demosaic 演算法調整假色抑制參數或換 demosaic 演算法

進階挑戰題

  1. 在同一張 SFR chart 上，分别測量「NR off + Sharpen off」vs「NR on + Sharpen on」的 MTF 曲線，畫出兩條 SFR 曲線的差異，標出「真實解析度」vs「銳化提升」。
  2. 設計一個 Moiré 風險評估流程：在你的應用場景中，哪些紋理最可能產生 Moiré？如何在 demosaic 參數中取得 Moiré 抑制與 MTF 的平衡？
  3. 比較「中心 MTF50=0.5 + 角落 0.25」vs「中心 0.4 + 角落 0.35」哪種更適合你的應用，說明理由。
