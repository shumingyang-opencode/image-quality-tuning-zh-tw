16.1 完整工作流

量測基準→校正→美化→驗證→一致性→報告

16.2 校正順序（不可跳）

  1. 黑位（統計地基）。
  2. LSC（均勻度）。
  3. AWB/CCM（色彩）。
  4. 曝光基準（AE）。

16.3 美化順序

  1. NR ↔ Sharpen（成對）。
  2. Tone/HDR。
  3. 色彩喜好微調。

16.4 驗收清單

checklist
□ 曝光誤差 < 5%
□ ΔE avg < 3
□ MTF50 ≥ 規格
□ 暗角比 ≥ 0.9
□ SNR 依規格
□ unit-to-unit 在規格內
□ 報告輸出

16.5 總複習

  1. 把 16 單元串成你的 SOP。
  2. 建立「量測→調校→驗證→報告」模板。
看完這單元你應該能說出：
  • 完整工作流。
  • 校正/美化順序。
  • 驗收清單。
