16.1 完整工作流

量測基準→校正→美化→驗證→一致性→報告

16.2 校正順序（不可跳）

  1. 黑位（統計地基）。
  2. LSC（均勻度）。
  3. AWB/CCM（色彩）。
  4. 曝光基準（AE）。

16.3 美化順序

  1. NR ↔ Sharpen（成對）。
  2. Tone/HDR。
  3. 色彩喜好微調。

16.4 驗收清單

checklist
□ 曝光誤差 < 5%
□ ΔE avg < 3
□ MTF50 ≥ 規格
□ 暗角比 ≥ 0.9
□ SNR 依規格
□ unit-to-unit 在規格內
□ 報告輸出

16.5 總複習

  1. 把 16 單元串成你的 SOP。
  2. 建立「量測→調校→驗證→報告」模板。

16.6 深入：調校的「回歸守則」

  • 每次改動跑「快照場景」回歸（色彩/雜訊/解析度）。
  • 用 EMVA 參數當「根因檢查」：調不上去先看感測器。
  • 參數進 git，附 log 與前後圖。

16.7 深入：從「會調」到「會驗收」

真正的能力不是「把這顆調好看」，而是「建立一套可重現、可比較、可驗收的流程」——把本課的 16 單元串成你的 SOP。

16.8 Worked Example：一顆感測器的完整流程

流程
1. EMVA：η/σ_d/DR（感測器確認）
2. 黑位校正 → 3. LSC → 4. AWB/CCM
5. AE 基準 → 6. NR ↔ Sharpen
7. 驗證：SNR/ΔE/MTF/暗角比 全過
8. unit-to-unit：5 台抽查
9. 出報告 + SPEC 對照

動手：照此 SOP 走完你手上的一顆感測器。

EMVA 1288 對應：工作流中的 EMVA 位置

EMVA 1288 是感測器層的標準量測（QE、飽和、雜訊、動態範圍）。它定義了「感測器送出 RAW 的品質天花板」——以下與本單元對應的規範、公式與調校方向。

EMVA 1288 參數公式/定義本單元驗證
先 EMVA 後 ISP先測感測器（EMVA），再調 ISP根因導向
數值很差時怎麼調（「調不上去」）：
  • 現象：tuning 撞牆通常是感測器達不到。
  • 調校方向：回 EMVA 1288：確認 η/飽和/雜訊是否符合預期；感測器上限確定後，才知道該補光、換感測器、還是只能接受。

本單元 EMVA 門檻總結

出貨門檻檢查
η ≥ 40% · σ_d < 5 e⁻ · DR ≥ 60 dB
SNR(中灰) ≥ 30 dB · PRNU < 2% · 壞點 < 0.1%

16.9 練習：完成一輪可交付工作流

  1. 先固定 D65、溫度、鏡頭、FW 與圖卡，取得 EMVA 1288 暗框/亮框基線。
  2. 依序跑黑位、LSC、AWB/CCM、AE，再調 NR/Sharpen 與 tone；每次只改一組參數。
  3. 用 ISO 12233 SFR/MTF、ISO 15739 雜訊、ISO 14524 OECF 及色卡驗證輸出。
  4. 以 5 台以上做 unit-to-unit，將 SNR、DR、MTF50、ΔE、暗角比與離群值寫入報告。
完成條件
□ 每一項 PASS 都有 raw、圖、公式、單位與條件

16.10 補強：停止條件與回退策略


當 NR 提升 SNR 卻使 MTF 下降、CCM 降低平均 ΔE 卻放大單色誤差、或 tone 保留暗部卻造成高光 clipping，應回到 SPEC 的優先序，不要無限調參。保留每個候選版本與回歸結果；若 sensor 的 η、滿阱或暗雜訊已是瓶頸，將問題升級到硬體/光學，而不是繼續堆 ISP。
