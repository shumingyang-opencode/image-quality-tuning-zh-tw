5.1 AWB 原理與 gains

AWB 算出一組 R/G/B gains 讓中性色中性。色溫趨勢：低色溫補 R、高色溫補 B。

色溫典型 RedGain典型 BlueGain
3000K1.71.2
6500K1.11.6
7500K1.02.0

5.2 灰卡校正

  1. 拍灰卡（標準光源）。
  2. 調 gains 直到 R=G=B。
  3. 記錄色溫→gains 表。

5.3 CCM 與 ΔE 驗證

CCM 是 3×3 矩陣，把 sensor RGB 校正到目標色彩空間。驗證用 ΔE（CIE DE2000）：

色彩保真度門檻
平均 ΔE00 < 3
單色最大 ΔE00 < 6
（以 24 色卡、D65 光源為基準）

5.4 分色溫 CCM

感測器對不同色溫光譜響應不同 → 分兩套 CCM（低/高色溫）並依 AWB 色溫插值。驗收需在至少兩個色溫下量 ΔE。

5.5 常見問題

  • 色偏 → gains 與 CCM 沒一起看。
  • 過飽和 → CCM 對角過大。
  • 色溫突變 → 分段 CCM 未平滑。

5.6 練習

  1. 灰卡校正並記錄 gains 表。
  2. 色卡量 ΔE，確認達標。

5.7 深入：灰卡校正是「中性基準」

灰卡校正讓「感測器的中性點」定義清楚——之後的 CCM 與喜好都建立在這個基準上。基準歪，一切歪。

5.8 深入：ΔE 的計算注意

  • ΔE 需在「相同色彩空間與白點」下計算（sRGB vs XYZ）。
  • 低飽和色 ΔE 易小、高飽和色易大——看分布而不只看平均。
  • 報告要標光源與色溫（D65 的 ΔE 不能跟 TL84 比）。

5.9 Worked Example：灰卡校正的完整流程

範例
D65 灰卡拍攝
讀出 R=210, G=190, B=170（RAW 均值）
R gain = 190/210 ≈ 0.90
B gain = 190/170 ≈ 1.12
套用後重拍 → R≈G≈B ✓
記錄 (D65: Rg=0.90, Bg=1.12)

動手：照此流程校正一組 gains，並在不同色溫重複。

EMVA 1288 對應：感測器線性度與色彩

EMVA 1288 是感測器層的標準量測（QE、飽和、雜訊、動態範圍）。它定義了「感測器送出 RAW 的品質天花板」——以下與本單元對應的規範、公式與調校方向。

EMVA 1288 參數公式/定義本單元驗證
線性度μ_y(μ_p) 應近線性；偏離影響色彩色彩校正的前提
黑位穩定σ_y.dark 隨時間穩定AWB 灰點判斷的可信度
數值很差時怎麼調（ΔE 高 / 色偏）：
  • 現象：EMVA 線性度差或黑位漂移 → 色彩校正建立在「歪的地基」上。
  • 調校方向：先確認感測器線性度與黑位（EMVA 量測）→ 再重做灰卡 AWB 與 CCM；色彩問題常源於感測器層非 CCM 本身。

本單元 EMVA 門檻與數值差調校

量測門檻差時調校
線性度（R²）≥ 0.999非線性 → 檢感測器/增益分段
黑位漂移同曝光 σ 小、mean 穩定漂移 → 感測器溫度/增益

5.10 補強：AWB、CCM 與 LSC 的順序

AWB 依賴可靠的中性像素，LSC 未校正時角落的通道比例可能被誤判為色偏；因此先固定光源與曝光，確認黑位與 LSC，再求 AWB gains，最後用 24 色卡求 CCM。CCM 只能修正色彩空間映射，不能修復飽和、黑位漂移或光源光譜缺失。

色彩診斷表
灰卡 R/G/B 不等 → 查 AWB gains、LSC、黑位

5.11 補強練習：跨色溫驗收


  1. 在 A、D65、TL84 各拍灰卡與 24 色卡。
  2. 記錄 AWB gains、平均/最大 ΔE 與每色塊分布。
  3. 比較單一 CCM 與分色溫 CCM，確認改善不是以灰階偏色換來。

進階真實情境 Worked Example：混合光源 AWB + GMCC + CCM


進階範例：賣場混合光源色彩校正
場景：賣場同時有 LED（6500K）+ 白熾（3000K），AWB 失效。

工作流：
1. AWB 灰點檢測 → 混合光源無明確灰點
2. GMCC（Gray World + Color Constraints）：
   強制場景平均色彩趨向灰色 + 色彩範圍約束
3. 拍攝場景 → 手動選取 ROI 校正 AWB gains
4. 用場景專屬 CCM（非 D65 標準 CCM）
5. 驗證：場景中白紙 ΔE < 4（放寬因混合光源）

為什麼選這條路徑：
標準 AWB 假設「單一光源」→ 混合光源需要
場景感知的 AWB + 專屬 CCM 才能兼顧自然感。


動手：在混合光源場景測試 GMCC 與標準 AWB 的差異。


為什麼選這條調校路徑：標準 AWB 假設單一光源，混合光源場景需要場景感知的 GMCC 演算法配合專屬 CCM，才能在色準與自然感之間取得平衡。



進階原理：AWB 靈敏度矩陣與 metamerism


AWB 的核心是「靈敏度矩陣」——描述「色溫變化 ΔT 時，R/B gain 需要變化多少」。然而 metamerism（同色異譜）是 AWB 的天敵：兩種光譜完全不同的光源可能產生相同的色溫讀數，但 AWB 給出相同的 gains 時色彩結果不同。


Metamerism 陷阱
光源 A：D65（色溫 6500K）
光源 B：LED 6500K（SPD 不同）
AWB 給出相同 gains → 但 CCM 輸出色彩不同！

原因：CCM 是針對特定 SPD 訓練的 →
換光源 SPD 時 CCM 不適用。


陷阱案例：「同一色溫下 AWB 正確就以為沒問題」——不同光源的 SPD 不同時，AWB 可能給出相同 gains 但色彩結果完全不同。
