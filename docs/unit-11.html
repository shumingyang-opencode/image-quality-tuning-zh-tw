SNR、DR、雜訊、MTF、ΔE 的公式與門檻

11.1 雜訊與動態範圍

核心公式
SNR = 20·log10(S / σ)                 (dB)
DR  = 20·log10(S_sat / σ_noise)       (dB)
σ_temporal = std(多幀同點)

11.2 色彩

ΔE00（CIE DE2000）
ΔE00 = f(ΔL, ΔC, ΔH, 加權項)
門檻：平均 < 3，單色 < 6

11.3 解析度

MTF50
MTF50 = SFR(f) 降至 50% 時的頻率
門檻依應用：手機 ≥ 0.4–0.6

11.4 一致性

unit-to-unit
Δparam = |單位值 − 群組平均| / 群組平均
門檻：多數 < 5–10%

11.5 完整公式速查

所有公式集中於公式速查頁。

11.6 練習

  1. 用黑框/灰框量測 SNR。
  2. 色卡算 ΔE。

11.7 深入：公式的「適用前提」

公式前提/限制
SNR = 20·log10(S/σ)需先定義 σ（時間性/空間性）
DR = 飽和/雜訊底需定義雜訊底（read? dark?）
ΔE00需同色彩空間/白點
MTF50需標單位與量測條件
最大的坑：「數字看起來對，但沒人知道怎麼量的」——每個公式都要附量測定義。

11.8 深入：EMVA 1288 公式的實用性

EMVA 1288 的公式是「感測器層的物理真相」——ISP 調校前先看它，才知道極限在哪。例如：SNR 上不去 → 是 η 低（感測器）還是增益過高（操作點）？

11.9 Worked Example：一組完整驗證

範例
灰框：S=400, σ=21 → SNR 25.6 dB
暗框：σ_d=8 e⁻
DR（EMVA）≈ 70 dB
色卡：ΔE avg 2.4, max 5.1 ✓
SFR：MTF50 0.52 ✓
暗角比 0.95 ✓
unit-to-unit（5台）：AWB gains ±3% ✓

動手：把你系統的六項指標跑一遍，對照門檻。

EMVA 1288 對應：完整公式集

EMVA 1288 是感測器層的標準量測（QE、飽和、雜訊、動態範圍）。它定義了「感測器送出 RAW 的品質天花板」——以下與本單元對應的規範、公式與調校方向。

EMVA 1288 參數公式/定義本單元驗證
平均訊號μ_y = μ_y.dark + η·μ_p訊號模型
變異σ_y² = σ_y.dark² + η·μ_pshot+read
SNRSNR = μ_y / σ_y品質指標
DRDR = μ_p.sat / √(μ_p.min)範圍
數值很差時怎麼調（整體指標差）：
  • 現象：EMVA 參數互相連動（η/飽和/雜訊）。
  • 調校方向：以 EMVA 1288 為「根因工具」：先測感測器，再決定 ISP 調校——感測器達不到的，ISP 補不回來。

EMVA 1288 門檻值速查（典型範圍，依感測器製程與應用）

參數優（佳）一般差（需檢討）影響

時間性暗雜訊 σ_d< 3 e⁻3–10 e⁻> 10 e⁻低光雜訊底
飽和容量 μ_e.sat> 30k e⁻10k–30k e⁻< 10k e⁻動態範圍

11.10 補強：公式的單位與誤差傳播

先保持線性域再轉 dB：SNR 的均值與 σ 必須來自同一 ROI、同一 bit depth；若用 10·log10 變異量，必須說明它與 20·log10 振幅比的關係。DR、SNR、MTF50、ΔE 不可直接平均成一個畫質分數，應各自保留原始值與不確定度。

驗證紀錄最小欄位
指標 | 原始量 | 公式 | 單位 | ROI/幀數 | 門檻 | 結果

11.11 補強練習：手算與工具交叉驗證


  1. 用一組均值與 σ 手算 SNR、用腳本或試算表重算。
  2. 用飽和訊號與暗雜訊估算 DR，確認 dB 轉換沒有把線性比誤當 dB。
  3. 把 MTF50 單位、ΔE 白點與 SNR 幀數補進結果表，找出三個原本不可重現的欄位。
