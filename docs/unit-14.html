標準主題量什麼

ISO 12232感光度/雜訊ISO speed、雜訊
ISO 15739雜訊temporal/spatial
ISO 14524階調OECF

ISO 19084陰影shading

14.2 EMVA 1288（感測器特性）

EMVA 1288 是感測器層的標準量測：量子效率、飽和容量、時間/空間雜訊、動態範圍、SNR。

地位：EMVA 1288 是「感測器 datasheet 與 tuning 的基礎」——它的數字直接決定 IQ 天花板。

14.3 IEEE CPIQ 與商用評分

  • CPIQ：手機相機畫質評分框架。
  • DXOMark：商用評分。

14.4 標準的用途

  • 量測「可與別家比較」。
  • 報告「可被客戶接受」。
  • 規格書「可被驗證」。

14.5 練習

  1. 列出 ISO 標準族。
  2. 說明 EMVA 1288 的地位。

14.6 深入：ISO vs EMVA 的分工

標準層級用途
EMVA 1288感測器感測器特性/規格
ISO 12233…相機/鏡頭解析度/雜訊/色彩
CPIQ整體畫質主觀-客觀對應評分

14.7 深入：EMVA 1288 量測要點

  • 恆溫（暗電流敏感）。
  • 曝光校準（避免飽和/太暗）。
  • 多幀統計（降噪誤差）。

14.8 Worked Example：EMVA 報告閱讀

範例
某感測器 EMVA 報告：
η = 52%（可見）✓
σ_d = 4 e⁻（佳）✓
μ_e.sat = 28k e⁻（佳）✓
DR = 74 dB ✓
PRNU = 1.2% ✓
→ 感測器層 OK → 可進行 ISP 調校

動手：讀一份真實 EMVA 報告，判斷各參數等級。

EMVA 1288 對應：EMVA 1288 完整規範

EMVA 1288 是感測器層的標準量測（QE、飽和、雜訊、動態範圍）。它定義了「感測器送出 RAW 的品質天花板」——以下與本單元對應的規範、公式與調校方向。

EMVA 1288 參數公式/定義本單元驗證
量測條件溫度、曝光、光源標準化可比較性
參數集η、飽和、DSNU/PRNU、SNR、DR、暗電流感測器規格書
數值很差時怎麼調（規格書與 EMVA 不符）：
  • 現象：廠商 datasheet 的 EMVA 數字與自測不符。
  • 調校方向：以同一 EMVA 版本與量測條件重測；確認溫控與光源後再下結論——EMVA 是「講同種語言」的基礎。

14.9 補強：標準不是門檻的替代品

ISO 與 EMVA 主要定義量測對象、條件與計算方法；「≥ 30 dB」或「MTF50 ≥ 0.5 c/p」仍需由應用、鏡頭、感測器與客戶 SPEC 決定。報告引用標準時要寫版本、測試層級、圖卡/光源、ROI、曝光與是否套用 ISP，避免把不同層級的數字直接比較。

需求方法標準報告補充
解析度ISO 12233 SFRMTF50 單位、中心/角落、銳化狀態
雜訊/ISOISO 15739/12232曝光、色彩通道、temporal/spatial 定義
感測器天花板EMVA 1288η、飽和、σ_d、PRNU/DSNU、溫度

14.10 補強練習：做標準對照矩陣

  1. 為 SNR/DR、MTF、OECF、flare、shading 各指定一個方法標準。
  2. 為每個標準補上測試條件、輸出指標與專案門檻。
  3. 標記哪些數字來自 EMVA sensor 層，哪些來自相機輸出層。
