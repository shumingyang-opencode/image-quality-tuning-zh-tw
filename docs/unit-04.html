4.1 曝光三要素與 SNR

曝光（Texp）、類比增益、數位增益共同決定亮度。由 SNR 數學知：加曝光 > 加增益。

Texp→G_ana（類比）→ADC→G_dig（數位）
調校順序鐵則：先 Texp → 再 G_ana → 最後 G_dig。

4.2 測光模式與適用場景

模式演算法適用
矩陣全畫面加權一般
中心加權中間權重高人物置中
點測光單點精準主體

4.3 AE 收斂的驗證公式

曝光目標（18% 灰）
目標 L = 0.18 × 飽和值（10-bit → ~184）
誤差 = |L_量測 − L_目標| / L_目標
門檻：|誤差| < 0.05（5%）

收斂速度：AE 應在 N 幀內穩定（常見 5–15 幀）。

4.4 常見問題

  • 過暗 → AE 受限（快門/增益上限）。
  • 過亮 → 測光區域含高亮。
  • 閃爍 → 收斂參數過激。

4.5 練習

  1. 灰卡下驗證曝光目標誤差。
  2. 背光場景試測光模式。

4.6 深入：AE 的「測光目標」選擇

測光目標（18% 灰 vs 臉部 vs 高光）決定「什麼叫正確曝光」——不同應用不同目標：

  • 一般拍照：18% 灰。
  • 人像：臉部亮度優先。
  • 機器視覺：訊號飽和度優先（避免 clipping）。

4.7 深入：AE 與 EMVA SNR 的連結

AE 決定了「操作在 SNR 曲線的哪一點」。低光時 AE 若先拉增益 → SNR 差；EMVA 的 SNR 曲線是「AE 該選哪個曝光/增益組合」的依據。

4.8 Worked Example：AE 收斂誤差計算

範例
灰卡拍出平均亮度 = 172（10-bit）
目標 = 0.18 × 1023 ≈ 184
誤差 = |172 − 184| / 184 ≈ 6.5%
→ 超過 5% 門檻 → 調整 AE 目標或增益

再測：曝光 +10% → 亮度 189 → 誤差 ≈ 2.7% ✓

動手：灰卡下實測 AE 誤差，調整到 <5%。

EMVA 1288 對應：曝光與 SNR

EMVA 1288 是感測器層的標準量測（QE、飽和、雜訊、動態範圍）。它定義了「感測器送出 RAW 的品質天花板」——以下與本單元對應的規範、公式與調校方向。

EMVA 1288 參數公式/定義本單元驗證
量子效率 ηη = μ_y.dark 以上斜率 / μ_p曝光目標的訊號基礎
SNR（shot 主導）SNR = η·μ_p / √(σ_d² + η·μ_p)曝光/增益調校的依據
數值很差時怎麼調（SNR 差（低光））：
  • 現象：EMVA 量測顯示 SNR 遠低於 shot-limited 理論值。
  • 調校方向：先加曝光（Texp）→ 再檢視類比增益上限 → 確認感測器是否操作在 shot 主導區（若 read noise 主導，降增益不如補光）。

本單元 EMVA 門檻與數值差調校

量測門檻差時調校
SNR（目標照度）目標 ≥ 30 dB；差 < 20 dB加 Texp → 檢增益上限 → 補光
η≥ 40%（可見）η 低是感測器層問題，ISP 無法救

4.9 補強：AE、SNR 與 DR 的聯動

AE 不是只追求灰卡亮度。若快門受限，增加類比增益可維持輸出亮度，但讀出雜訊在暗部的比例可能上升；若能增加曝光，通常能提升光子數與 SNR。AE 的 target、highlight 保護與增益上限必須一起寫入 SPEC，否則同一場景會出現不同的 SNR/DR 結果。

判讀順序
灰卡誤差超標 → 先看 ROI/光源 → 看曝光是否飽和

4.10 補強練習：三種場景驗證 AE


  1. 用灰卡、背光與高反差場景各記錄收斂幀數及最終誤差。
  2. 固定亮度後比較「加曝光」與「加增益」的 SNR，寫出取捨理由。
  3. 把 AE target、上限、門檻與失敗照片加入報告。

進階真實情境 Worked Example：低光 + 逆光 AE 策略


進階範例：地下停車場出入口 AE
場景：監視攝影機，停車場內 5 lux + 出口逆光 50000 lux。

AE 策略：
1. 點測光鎖定車牌區域（避免被出口高光騙）
2. Highlight protect = 90%（防出口 clipping）
3. 增益上限 G_ana ≤ 12dB（保 SNR ≥ 20dB）
4. 快門上限 Texp ≤ 33ms（防運動模糊）

驗證：
- 車牌區亮度誤差 < 8%（略寬是因高反差）
- 出口無大面積 whiteout
- 低光 SNR ≥ 20 dB

為什麼這條路徑：
高反差場景不能只追求「灰卡準」→
要在 SNR、motion blur、highlight 保護三者間取捨。


動手：在你的高反差場景設計 AE 優先序。


為什麼選這條調校路徑：高反差場景不能只追求灰卡曝光準確——要在 SNR、運動模糊、高光保護三者間取捨，才能兼顧主體可辨識與整體階調。



進阶原理：AE 迴路的 PID 控制


AE 收斂本質是一個回饋控制迴路（類似 PID）。比例項（P）決定收斂速度，積分項（I）消除穩態誤差，微分項（D）抑制震盪。


AE 控制模型
error = target亮度 − 當前亮度
Δ曝光 = Kp×error + Ki×∫error + Kd×d(error)/dt

Kp 過大 → 亮度震盪
Ki 過大 → 收斂慢但穩態準
Kd 過大 → 過沖後回彈


陷阱案例：「把 AE 收斂調到最快」——Kp 過大會造成亮度在明暗間震盪，場景切換時尤其明顯（如從室內走到室外）。



診斷式疑難排解





症狀可能原因解決方案
