4.1 曝光三要素與 SNR

曝光（Texp）、類比增益、數位增益共同決定亮度。由 SNR 數學知：加曝光 > 加增益。

Texp→G_ana（類比）→ADC→G_dig（數位）
調校順序鐵則：先 Texp → 再 G_ana → 最後 G_dig。

4.2 測光模式與適用場景

模式演算法適用
矩陣全畫面加權一般
中心加權中間權重高人物置中
點測光單點精準主體

4.3 AE 收斂的驗證公式

曝光目標（18% 灰）
目標 L = 0.18 × 飽和值（10-bit → ~184）
誤差 = |L_量測 − L_目標| / L_目標
門檻：|誤差| < 0.05（5%）

收斂速度：AE 應在 N 幀內穩定（常見 5–15 幀）。

4.4 常見問題

  • 過暗 → AE 受限（快門/增益上限）。
  • 過亮 → 測光區域含高亮。
  • 閃爍 → 收斂參數過激。

4.5 練習

  1. 灰卡下驗證曝光目標誤差。
  2. 背光場景試測光模式。
