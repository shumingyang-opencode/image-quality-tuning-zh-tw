3.1 光源標準

IQ 量測必須在可控光源下進行。

光源色溫用途
D656500K日光標準
D505000K印刷/色彩標準
A（白熾）2856K低色溫測試
TL844000K室內螢光
陷阱：用非標準光源量測，結果不可再現、不能與別家比較。

3.2 測試圖卡

圖卡用途
18% 灰卡曝光/白平衡基準
24 色卡（X-Rite）色彩校正/ΔE
SFR chart（ISO 12233）解析度/MTF
均勻灰（積分球）雜訊/LSC

3.3 量測儀器

  • 積分球/均勻光源：均勻照明。
  • 光譜儀：光源光譜確認。
  • 照度計：lux 確認。
  • 分析軟體：Imatest / Python。

3.4 量測條件記錄

量測 log 範本
光源: D65  照度: 1000 lux
圖卡: 24 色卡  距離: 0.5m
曝光: 自動  增益: 1.0  AWB: off(4500K)

3.5 練習

  1. 列出你需要的測試圖卡清單。
  2. 建立你的量測條件 log 範本。

3.6 深入：光源穩定性的驗證

光源漂移檢查
拍多張灰卡，看均值是否穩定：
同一點跨幀 σ_temporal < 1%（否則光源/曝光不穩）
陷阱：光源閃爍（100/120Hz）會污染雜訊量測——用穩定直流光源或正確同步。

3.7 深入：圖卡對齊與距離

  • 圖卡須垂直於光軸、填滿畫面（依規格）。
  • SFR 斜邊角度（ISO 12233 建議 5°）影響 MTF 準度。
  • 距離/焦距改變解析度——固定記錄。

3.8 Worked Example：光源與曝光校準

範例
1. 光譜儀確認 D65（色溫 ±100K）
2. 照度計確認 1000 lux（±5%）
3. 拍灰卡 → 調曝光到 18% 灰（~184 @10bit）
4. 記錄全部條件到 log

動手：照此流程校準你的量測環境一次。

看完這單元你應該能說出：
  • 標準光源（D65/D50/A/TL84）。
  • 測試圖卡種類與用途。
  • 量測條件記錄的重要性。
