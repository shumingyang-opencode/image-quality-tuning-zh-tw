3.1 光源標準

IQ 量測必須在可控光源下進行。

光源色溫用途
D656500K日光標準
D505000K印刷/色彩標準
A（白熾）2856K低色溫測試
TL844000K室內螢光
陷阱：用非標準光源量測，結果不可再現、不能與別家比較。

3.2 測試圖卡

圖卡用途
18% 灰卡曝光/白平衡基準
24 色卡（X-Rite）色彩校正/ΔE
SFR chart（ISO 12233）解析度/MTF
均勻灰（積分球）雜訊/LSC

3.3 量測儀器

  • 積分球/均勻光源：均勻照明。
  • 光譜儀：光源光譜確認。
  • 照度計：lux 確認。
  • 分析軟體：Imatest / Python。

3.4 量測條件記錄

量測 log 範本
光源: D65  照度: 1000 lux
圖卡: 24 色卡  距離: 0.5m
曝光: 自動  增益: 1.0  AWB: off(4500K)

3.5 練習

  1. 列出你需要的測試圖卡清單。
  2. 建立你的量測條件 log 範本。

3.6 深入：光源穩定性的驗證

光源漂移檢查
拍多張灰卡，看均值是否穩定：
同一點跨幀 σ_temporal < 1%（否則光源/曝光不穩）
陷阱：光源閃爍（100/120Hz）會污染雜訊量測——用穩定直流光源或正確同步。

3.7 深入：圖卡對齊與距離

  • 圖卡須垂直於光軸、填滿畫面（依規格）。
  • SFR 斜邊角度（ISO 12233 建議 5°）影響 MTF 準度。
  • 距離/焦距改變解析度——固定記錄。

3.8 Worked Example：光源與曝光校準

範例
1. 光譜儀確認 D65（色溫 ±100K）
2. 照度計確認 1000 lux（±5%）
3. 拍灰卡 → 調曝光到 18% 灰（~184 @10bit）
4. 記錄全部條件到 log

動手：照此流程校準你的量測環境一次。

3.9 補強：設備不確定度與校準

圖卡邊緣、光源均勻度、照度計誤差與相機定位都會進入結果。先拍均勻灰確認中心到角落的照度變異，再以參考相機或標準色卡做日常 check；若基準漂移，先標記整批資料無效，不要用後處理修正測試設備。

檢查可接受記錄失敗時
光源色溫、照度、均勻度、日期重新校準或更換
圖卡版本、方向、距離、平整度重擺並拍定位照
相機焦距、溫度、曝光、FW鎖定參數再測

3.10 補強練習：做一次量測能力檢查

  1. 同一灰卡連拍 10 幀，計算均值與跨幀 σ。
  2. 把圖卡移到中心、左上、右下各拍一次，檢查照明與定位是否造成假性 LSC。
  3. 在報告中列出設備誤差來源與是否通過的判定。
看完這單元你應該能說出：
  • 標準光源（D65/D50/A/TL84）。
  • 測試圖卡種類與用途。
  • 量測條件記錄的重要性。

進階真實情境 Worked Example：積分球光源校準全紀錄

進階範例：積分球光源年度校準
場景：IQ 實驗室的積分球使用 2 年，需確認是否仍可信。

校準流程：
1. 用光譜儀量 D65 色溫 → 6520K（偏差 +20K，OK）
2. 用照度計量中心照度 → 985 lux（偏差 -1.5%，OK）
3. 拍均勻灰 → 中心到四角照度變異 < 2%（OK）
4. 用參考相機拍 24 色卡 → ΔE avg = 2.1（與基線差 0.3，OK）
5. 以上任一超標 → 標記該批次量測無效

為什麼這條路徑：
設備漂移是「隱性殺手」——光源色溫偏 200K →
AWB 基準歪 → 所有色彩量測都不可信。

動手：為你的量測設備建立年度校準 SOP。

為什麼選這條調校路徑：設備漂移是隱性殺手——光源色溫偏 200K 就會讓 AWB 基準歪斜，所有色彩量測連帶失效，必須定期校準。

進階原理：照度計 vs 光譜儀的量測差異

照度計量的是「總照度」（lux），光譜儀量的是「光譜功率分佈」（SPD）。同一照度下，LED 與白熾燈的 SPD 完全不同 → 對 AWB/CCM 的影響也不同。

陷阱案例：「用照度計確認 1000 lux 就以為光源正確」——照度計不區分色溫！同一 1000 lux，3000K 與 6500K 的 AWB 基準完全不同。必須搭配光譜儀確認 SPD。

診斷式疑難排解

症狀可能原因解決方案
灰卡拍出偏色光源色溫偏移或 AWB 未校正光譜儀確認光源 + 重做 AWB 校正
積分球照度不均積分球老化或漫射器污染更換漫射器或清潔後重校
量測結果逐月漂移光源壽命衰減建立光源壽命追蹤與定期更換 SOP
同一圖卡量測重複性差圖卡固定不穩或距離變化用治具固定圖卡 + 雷射測距
照度計與光譜儀讀數矛盾照度計未校準或光譜儀設定錯誤兩台互相交叉校準

進階挑戰題

  1. 設計一個「量測設備健康看板」：包含哪些設備需要追蹤、追蹤什麼指標、多久校準一次、超標時的處置流程。
  2. 為你的實驗室建立一份「量測不確定度評估表」：列出 A 類（統計）與 B 類（設備精度）不確定度來源，並計算合成不確定度。
  3. 找出一個「量測條件漂移」的真實案例（或模擬），說明漂移如何影響 IQ 結果，以及如何建立防線。
