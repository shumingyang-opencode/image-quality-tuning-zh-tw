7.1 雜訊物理

雜訊模型來源
shot noiseσ=√N光子隨機性
read noise常數讀出電路
dark current隨曝光/溫度暗電流
SNR 計算
σ_total = √(σ_shot² + σ_read²)
SNR = 20·log10(S / σ_total)   (dB)

7.2 雜訊量測方法

  • 黑框：read + dark noise。
  • 灰框：shot + read。
  • 多幀：分離 temporal vs spatial。

7.3 NR 的取捨

鐵律：NR 與細節是翹翹板。NR 過強 → 塑膠感；過弱 → 雜訊明顯。以「平坦區乾淨、紋理區保留」為目標。
  • 亮度降噪：影響細節。
  • 彩色降噪：抑制色斑，可稍強。
  • 時間降噪：多幀平均。

7.4 練習

  1. 量測 σ vs gain，決定增益上限。
  2. 調 NR，對比平坦/紋理區。

7.5 深入：NR 的「分頻段」調校

雜訊在高頻（細節）與低頻（平坦）表現不同——好的 NR 分頻段：

  • 低頻：強 NR（平坦區乾淨）。
  • 高頻：弱 NR（保留紋理）。

7.6 深入：時間性 vs 空間性雜訊的處理

  • 時間性（跨幀抖動）：時間降噪（多幀）。
  • 空間性（固定圖樣 FPN）：感測器/黑位校正，NR 救不了。
判別：拍多幀，若固定不變的圖樣 → FPN；隨機抖動 → 時間性。

7.7 Worked Example：SNR 與增益

範例
灰框（18%）：均值 S=400, σ=21
SNR = 20·log10(400/21) ≈ 25.6 dB（偏低）

檢查：σ_d（暗框）= 8 e⁻；shot 主導 ✓
調校：曝光×2（S=800, σ≈31）
SNR = 20·log10(800/31) ≈ 28.2 dB
再補光：S=1200 → SNR ≈ 30 dB ✓

動手：量測你的 SNR，用「曝光優先」改善。

EMVA 1288 對應：雜訊（EMVA 1288 核心）

EMVA 1288 是感測器層的標準量測（QE、飽和、雜訊、動態範圍）。它定義了「感測器送出 RAW 的品質天花板」——以下與本單元對應的規範、公式與調校方向。

EMVA 1288 參數公式/定義本單元驗證
時間性暗雜訊σ_y.dark = √(σ_d²)黑框量測
shot noiseσ_y² = σ_y.dark² + η·μ_p灰框量測
SNRSNR = μ_y / σ_y整體雜訊指標
數值很差時怎麼調（SNR / 雜訊差）：
  • 現象：EMVA 顯示 read noise 高或 shot 主導但 η 低。
  • 調校方向：read noise 高 → 檢查增益設定/感測器操作點；η 低 → 感測器層問題（非 ISP 可救）；可接受則降噪收尾。EMVA 數字決定「NR 的極限」。

本單元 EMVA 門檻與數值差調校

量測門檻差時調校
σ_d< 3 e⁻ 佳；> 10 e⁻ 差高 → 檢操作點/增益
SNR（中灰）≥ 30 dB低 → 先曝光後增益；感測器極限內
DR≥ 60 dB低 → 飽和/雜訊底方向

7.8 補強：SNR 曲線要分清感測器與 NR

先在 RAW 或 NR 關閉狀態量測均值、跨幀 σ 與空間 FPN，建立 EMVA 1288 的 sensor baseline；再開啟 NR，比較平坦區 SNR、紋理保留與 MTF。若 NR 後 SNR 變好但 MTF50 掉很多，這是偏好的取捨，不代表感測器變好。

NR 回歸表
ISO/增益 | RAW SNR | NR 後 SNR | MTF50 | 紋理觀察

7.9 補強練習：找出最佳操作點


  1. 在三個照度與三個增益各拍黑框、灰框、紋理圖。
  2. 繪出 SNR 對照度曲線，標示 read-noise 主導轉為 shot-noise 主導的位置。
  3. 以「平坦區 SNR、MTF50、紋理主觀評分」三欄決定 NR 強度，而不是只看單一 dB。

進階真實情境 Worked Example：低光 NR + Sharpen 聯合調校


進階範例：夜間監視 NR + Sharpen 取捨
場景：5 lux 夜間監視，SNR 要求 ≥ 20dB，車牌需可辨識。

調校流程：
1. RAW SNR = 15 dB（不足）→ NR 開啟
2. Temporal NR（2 幀平均）→ SNR +6dB = 21dB ✓
3. Spatial NR 強度 3/10（保留紋理）
4. Sharpen 強度 4/10（拉回 MTF，避免 halo）
5. 驗證：SNR=21dB, MTF50=0.42, 紋理保留 ✓

為什麼選這條路徑：
時間降噪不傷 MTF → 優先使用 →
空間降噪只補足不足的部分 → Sharpen 最後拉回。


動手：在低光場景用「時間優先」策略調 NR。


為什麼選這條調校路徑：時間降噪不損傷空間解析度，應優先使用；空間降噪只補足時間降噪的不足，Sharpen 最後才拉回 MTF——這是低光 NR 的黃金順序。



進階原理：雜訊功率譜密度與頻域 NR


雜訊在頻域有功率譜密度（PSD）。白雜訊的 PSD 是平坦的；1/f 雜訊在低頻更強。頻域 NR 可以針對不同頻段施加不同強度的降噪，比純空間域 NR 更精準。


陷阱案例：「空間域 NR 調到最好看 → 頻域檢查發現低頻雜訊完全沒處理」——因為空間域 NR 的 kernel 大小有限，對低頻（大範圍亮度波動）無效。必須結合頻域 NR。
