6.1 Lens Shading 成因

鏡頭邊緣亮度 ∝ cos⁴(入射角)，加上微透鏡/濾鏡的入射角響應 → 四周變暗、可能偏色。

6.2 LSC 網格

  • 畫面切網格，每節點存 R/Gr/Gb/B 增益。
  • 節點間插值；分通道（偏色要獨立校正）。

6.3 驗證公式：暗角比

暗角比（shading ratio）
暗角比 = 角落亮度 / 中心亮度
門檻：校正後 > 0.9（原可能 0.7）
分通道：R/G/B 各算一次（檢查偏色）

6.4 調校流程

  1. 積分球拍均勻灰。
  2. 計算四通道增益圖。
  3. 寫入網格 → 再量測驗證。

6.5 常見問題

  • 換鏡頭後又暗 → LSC 是組合特有。
  • 角落偏色 → R/G/B 網格未獨立。
  • 網格邊界不連續 → 節點太疏。

6.6 練習

  1. 量測校正前後暗角比。
  2. 確認四通道各自 ≥0.9。

6.7 深入：LSC 的量測與回歸

  1. 積分球拍均勻灰（多張平均降雜訊）。
  2. 算四通道增益圖 → 平滑 → 寫入網格。
  3. 回測：暗角比 ≥ 0.9、四通道一致。
陷阱：鏡頭光圈/焦距/模組距離變 → shading 曲線變 → 要重做。量產前鎖定鏡頭。

6.8 深入：PRNU 與 LSC 的分工

LSC 補「鏡頭」的陰影；PRNU（感測器空間不均）要感測器端校正。先分離兩者（EMVA 均勻照明量 PRNU），才不會把感測器不均誤當鏡頭硬調。

6.9 Worked Example：暗角比量測

範例
積分球灰卡（中央 = 200）
四角 = 140 / 138 / 142 / 139
暗角比 = 140/200 ≈ 0.70（未校正）
LSC 校正後 → 四角 ≈ 190 → 0.95 ✓

動手：量測你系統校正前後的四角暗角比。

EMVA 1288 對應：空間均勻性（PRNU/DSNU）

EMVA 1288 是感測器層的標準量測（QE、飽和、雜訊、動態範圍）。它定義了「感測器送出 RAW 的品質天花板」——以下與本單元對應的規範、公式與調校方向。

EMVA 1288 參數公式/定義本單元驗證
PRNUPRNU = σ_spatial(light) / μ_light暗角/LSC 的感測器成分
DSNUDSNU = σ_spatial(dark)黑位不均/固定圖樣
數值很差時怎麼調（暗角比低）：
  • 現象：暗角可能混合了鏡頭 shading（cos⁴）與感測器 PRNU。
  • 調校方向：先用 EMVA 均勻照明量 PRNU——若 PRNU 高，先做感測器端校正再調 LSC 網格；避免把感測器不均誤當鏡頭陰影硬調。

本單元 EMVA 門檻與數值差調校

量測門檻差時調校
PRNU< 1%（佳）；> 2% 差高 → 感測器端校正再調 LSC
DSNU< 5 e⁻高 → 黑位校正/固定圖樣移除

6.10 補強：LSC 不只是一張亮度表

LSC 增益應由 RAW 四通道分別估計，並在相鄰節點連續插值；過大的增益會同時放大角落雜訊與 PRNU。校正資料要綁定鏡頭、光圈、焦距、模組距離、色溫與曝光，換任一項都要判斷是否重建網格。

LSC 判讀
校正前暗角比低、PRNU 正常 → 鏡頭 shading，重建 LSC

6.11 補強練習：網格回測


  1. 以均勻灰拍校正資料，輸出每通道中心與四角均值。
  2. 套用網格後重測，報告暗角比、通道差與角落 SNR。
  3. 改變色溫或鏡頭距離一次，確認舊網格是否失效。


  

    看完這單元你應該能說出：
    
  • cos⁴ 陰影成因與分通道偏色。
  • LSC 網格機制。
  • 暗角比驗證公式（≥0.9）。

  


  



進階真實情境 Worked Example：雙鏡頭 LSC 差異校正


進階範例：雙鏡頭手機的 LSC 一致性
場景：手機主攝 + 超廣角，LSC 必須各自校正且切換時無色差。

工作流：
1. 主攝：積分球 → 暗角比 0.72 → LSC 網格 A
2. 超廣角：積分球 → 暗角比 0.55（畸變更大）→ LSC 網格 B
3. 交叉驗證：同場景切換 → 中心亮度差 < 3%
4. 色溫驗證：D65 + A 光源各做一次
5. 綁定鏡頭模組 ID → 量產時逐顆套用

為什麼這條路徑：
不同鏡頭的 shading 曲線差異大 →
共用一張 LSC 網格會造成切換色差。


動手：為雙鏡頭系統建立各自的 LSC 並驗證切換一致性。


為什麼選這條調校路徑：不同鏡頭的 shading 曲線差異很大，共用同一張 LSC 網格會在切換鏡頭時產生色差與亮度跳變，必須各自校正並綁定模組。



進階原理：cos⁴ 以外的 shading 成因


LSC 不只補 cos⁴（入射角亮度衰減），還有微透鏡陣列的入射角響應（micro lens shading）、IR 濾鏡的入射角位移、以及感測器井深不均。這些因素疊加後，實際 shading 曲線往往比純 cos⁴ 複雜。


陷阱案例：「用 cos⁴ 模型預測 shading → 實際偏差 15%」——因為微透鏡與 IR 濾鏡的角響應不是 cos⁴ 可以描述的。正確做法：直接量測，不依賴理論模型。

症狀可能原因解決方案
